# 紧凑储物、媒体与小说展示设计

日期：2026-08-17

## 目标

优化桌侧储物、桌面外设、音乐歌词与书架互动：柜体更紧凑、播放器独立、歌词夜间更醒目、小说封面可悬浮展示。

## 家具与外设

- 冰箱和零食柜的实体高度各缩短为当前的一半，宽度与深度保持当前比例；仍为冰箱下、零食柜上，贴桌左端后墙。
- 两扇门的正面均朝房间中心。冰箱门绕外侧铰链向远离房间中心的一侧打开；零食柜玻璃门向房间中心打开。
- 无线鼠标几何整体放大到当前的 200%，保留滚轮、双键、尾灯和点击回弹。
- 键盘在夜间的 RGB 色带提高亮度与发光强度，白天效果不变。

## 音乐与歌词

- 顶部提示条恢复为仅展示物件说明；不再承载播放控制。
- 新增固定在页面底部中央的独立音乐控制台，播放时始终可见；仅提供上一首、当前曲名、下一首。
- 当前歌词移动到主显示器正上方，仅显示一行。
- 歌词按可用显示宽度自动缩放字号，避免长句被裁切；夜间使用高强度青紫荧光、描边和背后发光层，白天使用较轻发光。

## 小说封面互动

- `public/novel/` 的三张 WebP 图片构成封面池。
- 第一次点击书架时，从封面池随机选一张并抽出一本书，在书架前上方悬浮展示；只显示封面，不显示书页或文字。
- 再次点击同一书架时，悬浮封面和抽出书籍以动画放回；下次打开重新随机抽取。
- 悬浮封面使用纹理平面与线稿边框，面向房间中心，不遮挡电视或桌面。

## 验收

- 柜体高度各为当前一半、门向正确、独立开合仍正常。
- 鼠标视觉尺寸为当前两倍，键盘夜间亮度明显提高。
- 底部控制台与顶部提示条同时存在且互不影响；切歌仍同步音频和歌词。
- 每次仅显示一行完整歌词，夜间荧光效果明显。
- 书架点击在三张封面中随机展示一张；再次点击放回。
- `node --test tests/*.test.mjs` 与 `npm run build` 通过。
