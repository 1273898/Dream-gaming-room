# 桌左叠放储物与立体声播放器设计

日期：2026-08-17

## 目标

将储物组改为桌左侧靠后墙的紧凑叠放，并把两个桌面音响改为同一套可控制音乐、切歌和同步悬浮歌词的立体声播放器。机箱不作任何改动。

## 储物布局

- 冰箱位于下层，零食柜位于上层，整体位于电脑桌左端、贴后墙，正面朝房间中心。
- 两柜缩至相同宽深：约 0.66 宽 × 0.52 深；冰箱约 0.76 高，零食柜约 0.82 高。
- 维持独立点击开门；冰箱开启显示罐装饮料，零食柜开启显示薯片和零食。
- 机箱的位置、侧透方向和开机效果均不变。

## 立体声音响

- 两个音响共用唯一的播放器状态与同一个 HTMLAudioElement，作为一对左右声道而不是两个独立播放器。
- 点击任意音响：未播放时从当前曲目开始并循环播放；播放中时暂停并关闭悬浮歌词。
- 播放列表固定读取 `public/music/` 中两首同名 MP3/LRC：`把喜欢吹进风 (夏日版) - 雪球` 与 `オトノケ - Otonoke - Creepy Nuts`。
- 通过用户点击启动音频，符合浏览器禁止自动播放的限制；曲目结束后从头循环当前曲目。

## 顶部播放控制

- 当音响播放时，现有顶部信息条切换为迷你播放器布局。
- 控件仅包含“上一首”“当前曲名”“下一首”；上一首/下一首切换后立即继续播放并重置至新曲开头。
- 停止播放后，信息条恢复到普通的音响说明内容；不添加音量、进度条、随机或播放列表面板。

## 悬浮 3D 歌词

- 解析 `.lrc` 的时间标签，忽略元数据标签，形成按毫秒排序的歌词行。
- 在两只音响正上方、面向房间的位置渲染当前一句作为大号 3D 浮字；前一句与后一句用更小、更淡的字显示。
- 音频 `timeupdate` 驱动当前行更新；切歌或停止时清空歌词；夜间文字使用更亮的颜色以保持可读性。
- 歌词来自用户提供的本地 LRC 文件，仅在此房间中显示当前/相邻三行。

## 验收

- 储物组在桌左墙边上下叠放，冰箱在下、零食柜在上，机箱文件未变更。
- 点击任一音响都控制同一个播放状态；不会产生两个音频实例或叠加播放。
- 顶部播放器可以切换上一首和下一首，切换后音乐和歌词同步重置。
- 当前、前一、后一行 LRC 歌词在音响上方以 3D 形式同步更新。
- `node --test tests/*.test.mjs` 与 `npm run build` 通过。
