# 桌左侧上下叠放储物设计

日期：2026-08-17

## 目标

将零食柜和冰箱从电脑桌右侧改到桌子左端、贴后墙的紧凑上下叠放组，同时不改动机箱的位置、侧透方向和开机交互。

## 布局

- 储物组位于电脑桌左端与后墙之间，正面朝房间中心。
- 单门冰箱在下，缩小为约 0.66 宽 × 0.76 高 × 0.52 深。
- 单门玻璃零食柜在上，与冰箱同宽，约 0.66 宽 × 0.82 高 × 0.52 深。
- 零食柜底边与冰箱顶面之间保留 0.04 的视觉分隔；两者都不与桌腿、椅子或机箱重叠。
- 机箱维持当前坐标、侧透方向和所有动画，完全不修改 `Pc.tsx`。

## 交互

- 点击冰箱独立开合下层单门，打开后露出两层缩小的罐装饮料。
- 点击零食柜独立开合上层玻璃门，打开后露出薯片袋、薯片桶和零食盒。
- 开门角度、GSAP 缓动和 `useInteractive` 信息提示保持现有行为；只调整门枢轴和几何尺寸以适配新比例。

## 验收

- 储物组清晰位于桌子左侧并紧贴后墙，视觉为冰箱下、零食柜上。
- 两层柜体分别可点击开合，内容物不穿出柜体。
- 桌椅与机箱仍可正常看见和交互；机箱文件没有变更。
- `node --test tests/*.test.mjs` 与 `npm run build` 通过。
