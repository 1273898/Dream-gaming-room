# 密闭储物与可读桌面设计

日期：2026-08-17

## 目标

修正桌左侧柜门方向和密闭效果，使歌词真正以正向立体文字呈现在显示器上方，并把无线鼠标重做为清晰可辨的对称电竞鼠标。

## 密闭储物

- 冰箱与零食柜关闭时均由不透明完整门板遮住内部内容；冰箱不再透出饮料，零食柜不再透出薯片。
- 两个门板正面都朝房间中心。
- 冰箱和零食柜均从靠内部的铰链向外侧打开，打开方向远离房间中心；维持彼此独立的点击开合动画。

## 显示器上方立体歌词

- 歌词只显示当前一行，位置移动到主显示器上方正中央，面向椅子/房间中心；取消侧向旋转。
- 使用带 depth 的挤出式 3D 文本，并增加一层背后发光轮廓。
- 长歌词根据字符数降低字体大小并设定最大宽度，以完整显示在显示器上方。
- 夜间使用更强的青色面光、紫色边缘和背光；白天保留较弱效果。

## 对称电竞无线鼠标

- 整体仍为当前两倍视觉尺寸。
- 使用明显的左右按键壳体、中缝、滚轮槽、两侧拇指键、尾部 RGB 灯带和底部滑轨。
- 保留无线特性、点击灯效与按压回弹；不添加连接线。

## 悬浮轻小说实体书

- 书架抽出的随机小说封面保持原有随机和放回交互。
- 悬浮展示改为有厚度的实体书：正面使用随机封面贴图，侧面形成可见书脊与封底厚度。
- 仅呈现封面与书本几何，不增加翻页、内页文字或额外操作。

## 验收

- 关闭时两柜内部不可见，打开时对应内容清晰可见，门均向外侧打开。
- 单行歌词居中位于显示器上方、正对椅子，具有可见厚度且长句不裁切。
- 夜间歌词荧光明显强于白天。
- 鼠标一眼可辨为对称电竞无线鼠标，保持两倍大小与点击反馈。
- 悬浮小说封面具有可见书本厚度，放回交互正常。
- `node --test tests/*.test.mjs` 和 `npm run build` 通过。
