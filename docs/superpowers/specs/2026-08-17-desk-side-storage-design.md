# 桌侧储物与氛围更新设计

日期：2026-08-17

## 目标

保持现有 React Three Fiber 黑白线稿游戏房及点击交互风格，重做电脑桌旁的储物区域，并补足窗外昼夜贴图与墙面海报轮播。

## 布局

- 移除左墙的雷云灯及其点击闪烁逻辑。
- PC 主机保持在桌边地面；将机箱结构沿 X 方向镜像，使侧透玻璃朝房间可见方向，内部主板、显卡、风扇与 RGB 灯条仍能透过玻璃看到。
- 在电脑桌右侧、靠后墙的位置放置一组紧邻的零食柜与冰箱，避免遮挡椅子与主机。
- 零食柜靠近桌侧，冰箱紧邻零食柜外侧。二者的正面均朝房间中心，便于自由视角与桌旁近景看见开门动作。

## 交互与物件

### 零食柜

- 改为单扇玻璃门的窄高柜；点击整柜切换门的开/合。
- 门绕外侧铰链向房间方向打开；关闭时遮住内部，打开时展示三层陈列。
- 陈列以薯片袋、薯片桶与少量零食盒为主，并保留现有彩色点缀。

### 冰箱

- 改为桌侧协调尺寸的单门冰箱；点击整机切换门的开/合。
- 门绕外侧铰链向房间方向打开；关闭时遮住内部，打开时展示两层罐装饮料。
- 罐装饮料使用多色罐身与拉环细节；不新增独立拿取或库存状态。

### 机箱与鼠标

- 机箱点击开机逻辑不变：电源灯、前风扇旋转和内部 RGB 灯条继续工作。
- 鼠标改为无线款：删除连接线，保留拱形双键、滚轮与尾部灯环；点击切换灯光并播放按压回弹。

## 墙面与贴图

- 左墙海报框保留现有尺寸、位置、画框样式与点击循环机制。
- 指定图片 `微信图片_20260817152952_51_9.jpg` 加入左墙海报框的 `srcs` 轮播数组，与既有左墙图片一起循环。
- 窗户使用两张独立的海岸贴图，保持相同视角：白天为开阔海岸、晴空与暖日光；夜晚为深蓝海面、月光与远处灯火。
- 昼夜开关复用现有状态；仅切换窗景贴图，窗框和窗帘行为保持不变。

## 代码边界

- `Room.tsx`：移除雷云灯，接入窗景贴图及昼夜切换。
- `furniture.tsx`：替换桌侧零食柜、冰箱和无线鼠标的结构与开门动画。
- `devices/Pc.tsx`：镜像可见侧透与内部组件位置，保持既有开机交互。
- `data/posters.ts`：更新左墙轮播图片数组。
- `public/`：添加日/夜海岸窗景图片资产。

## 验收标准

- 雷云灯不再渲染，也不再有对应可点击热点。
- 从默认和桌旁视角均可看见机箱侧透与内部硬件。
- 零食柜与冰箱位于电脑桌旁，分别可独立开合；打开时分别清晰展示薯片与罐装饮料。
- 鼠标没有连接线，点击灯效和按压反馈正常。
- 左墙海报点击时在包含指定图片的数组中循环。
- 昼夜开关后，窗外完整替换为匹配的日/夜海岸贴图。
- `npm run build` 通过。
